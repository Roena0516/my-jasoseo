# my-jasoseo

Figma 자기소개서 양식(`이력서 자기소개서 양식` / Frame 47)을 그대로 옮긴 웹 편집기입니다.
브라우저에서 바로 글을 고치고, A4 PDF로 저장할 수 있습니다.

## 기능

- **Figma와 동일한 레이아웃** — 595 × 842pt(A4) 페이지, Pretendard, 좌표·간격·자간·행간을 Figma 값 그대로 pt 단위로 사용
- **바로 편집** — 모든 글자를 클릭해서 수정 (붙여넣기는 서식 없이 텍스트만)
- **구조 편집** — 문단/섹션에 마우스를 올리면 오른쪽에 버튼이 나타남
  - 섹션: 위·아래 이동(첫/마지막이면 이전·다음 페이지로 이동), 문단 추가, 삭제
  - 문단: 소제목 추가·제거, 위·아래 이동, 삭제
  - 페이지 아래: 섹션 추가, 페이지 추가·삭제
- **로고·서명 이미지 교체** — 이미지에 마우스를 올리면 변경/기본/제거
- **넘침 경고** — 내용이 페이지 하단 여백(40pt)을 넘으면 빨간 선과 안내 표시
- **자동 저장** — 브라우저(localStorage)에 자동 저장, JSON 백업 저장/불러오기, 초기화
- **PDF로 저장** — 인쇄 창에서 대상을 “PDF로 저장”으로 선택 (벡터 텍스트, A4, 여백 없음)

> PDF 저장 시 인쇄 설정에서 **여백: 없음**, **배경 그래픽: 켜기**가 기본값이 아니라면 맞춰 주세요. Chrome 기준으로 확인했습니다.

## 개발

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/
```

기본 문구는 `src/defaultContent.json`에 있습니다. 여기 내용을 바꾸면 “초기화” 시 돌아가는 기본값이 바뀝니다.
